把你的 MAA 接进来

按下面的步骤填一次，之后所有操作都在网页上完成

1. 复制你的用户标识符

这是 MAA 用来证明「它属于你」的密钥，请像密码一样保管，不要发到公开场合。

2. 在 MAA 里填写远程控制

MAA → 设置 → 远程控制，勾选启用后按下表填写：

MAA 设置项要填的内容
用户标识符 {{ user.user_key }}
获取任务端点 {{ public_base_url }}/maa/getTask
汇报任务端点 {{ public_base_url }}/maa/reportStatus
轮询间隔 1000 ms（默认值即可）

3. 回到这里刷新

MAA 配置好之后会立刻开始轮询，几秒内这台实例就会自动出现在首页。 你可以在实例详情页给它改名，然后把常用的「一键长草」「截图」「停止」挂上来。

返回首页

注意事项

  • 必须用 HTTPS。MAA 检测到端点使用 http 时每次连接都会弹不安全警告，明文传输还会泄露你的用户标识符。
  • 反向代理要放开请求体积。截图任务会把整张图以 Base64 回传（几十 MB），Nginx 需要 client_max_body_size 64m;。
  • 同一个账号可以接多台 MAA。它们共用同一个用户标识符，靠 MAA 自己生成的设备标识符区分。
  • MAA 重启不会丢任务。任务下发后若 15 分钟内没有回报会被标记为超时，重新点一次即可。
